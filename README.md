# trypointy.com

The Pointy website, served by GitHub Pages from `docs/` at https://trypointy.com.

- `docs/` — the published site (landing page, account pages, legal pages, the app download).
- `scripts/site/` — generator for the shared-layout pages: edit `scripts/site/pages/*.html` or
  `scripts/site/config.json`, then run `python3 scripts/site/build.py --check`.

The Pointy app itself is closed source and lives in a private repository.
